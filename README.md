# finance-manager-api

Express + MongoDB REST API backend for [finance-manager](https://github.com/dberardi2020/finance-manager). Handles purchases and subscriptions, deployable via Docker.

## Stack
- **Runtime:** Node.js, Express
- **Database:** MongoDB (Mongoose)

## Setup
Copy `.env.example` to `.env` and fill in your values, then:
```sh
docker-compose up
```
